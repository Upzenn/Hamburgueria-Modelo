# Brasa Alta — Modelo padrão de hamburgueria | Upzen

**Brasa Alta** é uma marca **100% fictícia** criada para demonstrar o visual e as funcionalidades de um site premium de hamburgueria. Este projeto não representa uma empresa real.

## Como abrir

Extraia o ZIP e abra `index.html` no navegador. Para desenvolvimento local, use o VS Code Live Server.

## O que funciona

- Categorias e pesquisa de produtos no cardápio.
- Personalização de hambúrgueres (queijos, adicionais, molhos e acompanhamentos).
- Carrinho com ajuste de quantidades e persistência no navegador.
- Simulação de pedido com nome, endereço e observações.
- Revisão do resumo e **cópia da comanda**: nenhum dado é enviado para terceiros.
- Experiência responsiva, animações e navegação por âncoras.

## Antes de personalizar para um cliente real

1. Substitua a marca fictícia, a logo (`assets/brasa-alta-logo.png`) e a arte (`assets/brasa-alta-brand-board.webp`).
2. Edite os textos de `index.html`, os produtos e valores definidos no início de `script.js`.
3. Substitua as imagens ilustrativas externas por fotos autorizadas da empresa.
4. Configure canais de contato e uma integração de pedidos **somente com autorização do cliente**. Este modelo **não contém contatos pessoais, links externos de pedidos ou integrações de mensageria**.
5. Edite `config.js` apenas se desejar informar a URL institucional da Upzen. O site funciona sem ela.

**Importante:** marca, produtos, preços, fotografias e pedidos desta demonstração são ilustrativos. As imagens de alimentos vêm de URLs externas do Unsplash e precisam de conexão para carregar.

## Identidade visual

A logo **Brasa Alta** foi gerada especialmente para este modelo, com ícone de hambúrguer amarelo, tipografia branca e dourada e assinatura “hamburgueria”. Os arquivos usados pelo site são `assets/brasa-alta-logo.png` (cabeçalho e rodapé), `assets/brasa-alta-brand-board.webp` (seção da marca) e `assets/favicon.png` (aba do navegador).
